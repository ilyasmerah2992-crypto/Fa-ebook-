Façebook mobile-first PWA starter.

Deploy: create a public GitHub repository, upload all files in this folder to its root, then Settings > Pages > Deploy from branch > main > /(root).

Working local demo: responsive UI, Arabic RTL, French/English language switching, navigation, local demo profile, local posts, likes, comments, simple search, PWA manifest/service worker.

Not production-ready: authentication is local only; posts are stored only in the current browser/device. Real accounts, secure login, cloud posts, image storage, friend graph, private real-time messaging, notifications, moderation and privacy/security controls require a backend such as Supabase and further implementation. Independent project, not affiliated with Facebook/Meta.
